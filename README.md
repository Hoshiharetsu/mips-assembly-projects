# MIPS Assembly Projects

This repository contains a collection of MIPS assembly programs demonstrating low-level programming concepts including system calls, integer arithmetic, bitwise operations, string handling, and modular subprogram design.

## Project Groups

- **Input/Output and System Calls**  
  Programs focused on console interaction, random number generation, sleep operations, and data input/output.

- **Arithmetic and Bitwise Operations**  
  Programs demonstrating shift-based multiplication, expression evaluation, and two's complement computation.

- **Strings, Subprograms, and Bit-Level Utilities**  
  Programs emphasizing reusable procedures, string handling, and custom utility routines for bit manipulation.
