# MIPS Assembly: User Input, Subprograms, and Utility Routines

## Overview
This collection of MIPS assembly programs focuses on user interaction, string handling, reusable subprograms, and custom utility routines.

---

## Programs Included

### Integer Input and Output
Prompts the user for an integer and prints it back.

### String Input and Output
Prompts the user for a string and prints it back.

### Shift Utility Driver Program
Tests reusable subprograms including:
- multiply by 10 using shifts
- right circular shift
- left circular shift

### Utility Subprogram Library
Provides reusable procedures for:
- input/output
- printing
- program control
- custom shift operations

---

## Concepts Demonstrated

- Integer and string input/output
- Memory allocation using `.space`
- Procedure calls (`jal`)
- Return flow (`jr $ra`)
- Register-based parameter passing
- Modular program structure
- Circular bit shifting

---

## Why This Matters

These programs demonstrate modular design in assembly, showing how reusable logic can be structured similarly to functions in high-level languages.

---

## What I Learned

- How to build reusable subprograms
- How to pass data between procedures
- How to structure larger assembly programs
- How modular design improves clarity

---

## How to Run

Use MARS or SPIM. Ensure included files (e.g., utilities) are in the same directory.
