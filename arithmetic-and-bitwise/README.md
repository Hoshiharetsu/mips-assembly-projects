# MIPS Assembly: Arithmetic and Bitwise Operations

## Overview
This collection of MIPS assembly programs focuses on integer arithmetic, expression evaluation, shift-based computation, and bitwise manipulation.

---

## Programs Included

### Multiply by 15
Computes multiplication using both shift-and-add logic and the `mult` instruction.

### Polynomial / Expression Evaluation
Evaluates a multi-step arithmetic expression based on user input.

### Integer Arithmetic Expression
Computes an arithmetic expression involving multiplication and division.

### Two's Complement Calculator
Calculates the two's complement of a user-provided integer.

---

## Concepts Demonstrated

- Integer arithmetic in MIPS
- Shift-based multiplication
- Use of `mult`, `div`, and `mflo`
- Bitwise operations (`xor`)
- Two's complement representation
- Register-based computation

---

## Why This Matters

These programs show how mathematical operations are implemented at the instruction level, reinforcing understanding of binary representation and CPU behavior.

---

## What I Learned

- How to break down arithmetic expressions into assembly instructions
- How to use shifts for efficient computation
- How binary operations affect integer values

---

## How to Run

Use MARS or SPIM to assemble and run each program.
